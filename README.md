# PasswordGenerator

PasswordGenerator — это десктопное приложение с графическим интерфейсом для удобной генерации и хранения паролей. Проект написан на Python с использованием фреймворка PyQt5 и библиотеки Pillow для динамической обработки изображений. База паролей хранится локально в SQLite, что обеспечивает полную автономность и безопасность работы приложения. Разработано в рамках учебной вычислительной практики.

## Требования

* Python 3.10 или новее.
* Git (для клонирования репозитория).

## Установка и запуск

Следуйте этим шагам, чтобы развернуть проект на своем компьютере:

1. **Склонируйте репозиторий:** `git clone https://github.com/Amadeyka/PasswordGenerator.git`
2. **Перейдите в папку с проектом:** `cd PasswordGenerator`
3. **Создайте виртуальное окружение:** `python -m venv venv`
4. **Активируйте виртуальное окружение:**
   * Для Windows (PowerShell): `.\venv\Scripts\activate` *(Если возникает красная ошибка безопасности, сначала выполните команду `Set-ExecutionPolicy RemoteSigned -Scope CurrentUser`, а затем повторите попытку активации).*
   * Для macOS/Linux: `source venv/bin/activate`
5. **Установите необходимые зависимости:** `pip install -r requirements.txt`
6. **Запустите приложение:** `python main.py`

## Особенности проекта
* Генерация паролей настраиваемой длины (от 4 до 50 символов).
* Настройка сложности: заглавные буквы, цифры, спецсимволы, исключение неоднозначных символов (0, O, 1, l).
* Динамический индикатор надежности пароля.
* Сохранение, редактирование и удаление записей (CRUD).
* Безопасная работа с локальной базой данных (`sqlite3`) с защитой от SQL-инъекций.
* Обработка и масштабирование изображений с помощью Pillow.
