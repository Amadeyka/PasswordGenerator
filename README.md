# Генератор паролей (Учебная практика)

Проект представляет собой десктопное приложение для генерации и безопасного хранения паролей. Разработано на Python с использованием графического фреймворка PyQt5.

## Функционал
* Генерация паролей настраиваемой длины (от 4 до 50 символов).
* Выбор используемых символов (заглавные буквы, цифры, спецсимволы).
* Опция исключения неоднозначных символов (0, O, 1, l).
* Автоматическая оценка надежности пароля.
* Сохранение, редактирование и удаление записей (CRUD).
* Загрузка и масштабирование иконок (Pillow).
* Безопасное хранение данных в локальной БД SQLite.
